# RAPPid Zoo — Ten Summons

A card-only [RAPP Vision](https://github.com/kody-w/rapp-vision) channel: ten
prompts, runnable verbatim against [kody-w/rappid](https://github.com/kody-w/rappid),
each one crossing a boundary the room assumes is hard.

**This repo IS the publish.** A public repo named `rappvision-*` with a
`channel.json` at its root is a RAPP Vision channel by convention — follow
`@kody-w` in the player's RAPP Hive and this channel subscribes itself. No PR,
no registry edit, no approval. Ships no media files: posters are inline SVG,
entries are title-card live scenes.

Watch it: https://kody-w.github.io/rapp-vision/
