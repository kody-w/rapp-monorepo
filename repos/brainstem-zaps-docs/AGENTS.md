# Public documentation repository guidance

Read `Agent.md` and `docs/security.md` before changing claims or examples.
This repository publishes documentation and harmless programs only. The
proprietary portable core, recipient providers, secrets, device bindings and
private execution outputs are not hosted here.

Keep examples capability-denied by default. A requested permission, signature,
filename or return value is not authority or proof of a side effect.
The capability kernel is embedded; never describe an external broker as a
mandatory runtime dependency.

Preserve truthful acceptance boundaries. Do not claim physical iOS,
OS entitlement enforcement, zero vulnerabilities, automatic safety of every
MCP/plugin, App Store acceptance or exact-once external effects.

Validate local links, example syntax against the installed private language,
and absence of user-specific paths, credentials or private session information
before publishing. Documentation alone is not an executable permission grant.
