# Patch Notes from Tomorrow

Create a 20–30 second deadpan fictional 2036 bulletin hosted by Kira Voss, an explicitly synthetic correspondent for the fictional channel `patch-notes-tomorrow`.

## Promise

One fictional patch event produces two testable future outcomes. The film orients; the live replay lets the viewer run both branches, compare them, and reset.

## Safety and truth

- Persistent on-screen label: **FICTION • SYNTHETIC • 2036 SIMULATION**.
- Kira Voss, Tomorrow Public Service, Civic OS 12, all places, metrics, and outcomes are invented.
- No real person, organization, outlet, product, or event is represented.
- All artwork, UI, narration, and sound are original or locally synthesized.

## Visual direction

Public-broadcast restraint: slate blue, warm paper, signal amber, civic red; Oswald headlines, IBM Plex Mono metadata. Use lower thirds, a future ticker, sober diagrams, and one surreal payoff: indoor queue weather with floating umbrellas.

## Replay

`live/index.html` must deterministically run Outcome A and Outcome B from the same patch event, preserve both results for comparison, and restore the baseline with Reset.
