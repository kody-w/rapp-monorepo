# Project Phoenix — Frequently Asked Questions

**Maintained by:** PMO (Oliver Brandt) · Updated monthly after PMO Sync.

## General

**Q: What is Project Phoenix?**
A: Meridian Manufacturing Group's transformation from SAP ECC 6.0 to SAP S/4HANA — new global
template, two go-live waves (December 2026 and June 2027). See the Program Charter.

**Q: When does my site go live?**
A: Wave 1 (December 2026): Munich M001/M002, Munich DC M003, Chicago U001, Detroit U002.
Wave 2 (June 2027): Lyon, Monterrey, Suzhou, Pune, São Paulo, Nagoya sites.

**Q: Who do I contact about my workstream?**
A: See the Workstream Directory — every stream lists a lead and a backup with email. If you don't
know the stream, start with the PMO (oliver.brandt@meridian-mfg.example).

## Working in the program

**Q: I'm blocked. What do I do?**
A: Raise it with your workstream lead. If it stays open more than 3 working days or crosses
workstreams, the lead escalates to the PMO (Oliver Brandt). Full path: Governance & Escalation.

**Q: Who approves a deviation from the global template?**
A: The Design Authority (chair: Elena Petrova, meets Thursdays). Custom code requires an
approved exception — fit-to-standard is the default.

**Q: Where do I find training for my role?**
A: The Phoenix Learning Portal (https://meridian-mfg.example/learning/phoenix) assigns a
role-based curriculum. Questions → **#phoenix-training** or Mark Daniels.

## Data & systems

**Q: Will I still see old ECC data after go-live?**
A: Yes — read-only in the ECC archive environment for 10 years. Only open items and current
master data migrate (Data Migration Playbook).

**Q: What happens to my reports?**
A: Wave 1 replaces the top 120 operational reports with Fiori/embedded analytics equivalents;
the mapping catalog lives on each stream site under Documents → Reporting.
