## Champions network

- 46 champions across Wave 1 sites (Munich 14, Dresden 8, Chicago 12, Detroit 6, DC/M003 6).
- Champions get early sandbox access, weekly enablement call (Fridays 13:00 CET), and a direct
  line to workstream leads for design questions.
- Nominate a champion: message Mark Daniels in **#phoenix-training**.

## Communications cadence

- Monthly all-hands "Phoenix Live" (recorded, posted to the Learning Portal).
- Site-level readiness dashboards reviewed at PMO Sync (Mondays).
- Go-live countdown comms start T-6 weeks, owned by Sofia Rossi.

## Training completion gates

Wave 1 go/no-go requires: ≥95% completion of role-based curricula and ≥90% sandbox exercise
pass rate for critical roles (finance close, order desk, warehouse, production supervisors).
