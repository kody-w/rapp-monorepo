## Purpose

This curriculum prepares a Strategic Sourcing Manager to work in SAP S/4HANA from the Wave 1 go-live on 15 December 2026. It is assigned automatically from the HR feed against the business role `MERI_MM_SOURCING`, so a user who changes role picks up the correct curriculum without a manual request. The content follows the global template: it teaches the standard process, and it teaches the exceptions the Procurement workstream has agreed, not local variants that the template retired.

## Prerequisites

- Active network account and an assigned business role in the training client (S4Q client 210).
- Programme orientation completed — it is the first item in the course list below.
- For hands-on items, a sandbox slot booked through #phoenix-training.

## Sandbox exercises (S4Q client 210)

| Ref | Exercise | Pass criterion |
|-----|----------|----------------|
| SOUR-E01 | Correct a document that failed validation | Error diagnosed and the document posted without help |

| SOUR-E03 | Run the daily routine for your role from start to finish | All steps completed inside the target handling time |
| SOUR-E04 | Use the Fiori search to find a record without a number | Record found from a partial description |

## Completion gate

Wave 1 go/no-go requires **≥95% completion** of this curriculum across the assigned population. This role is not on the critical list, so the sandbox exercises are strongly recommended but the 90% pass gate is not applied to it.

Completion is published weekly to site leads and to line managers. Users who have not started four weeks before go-live are chased by their site champion first and by Sven Andersson second.

## Assessment and record

Each virtual classroom ends with a short knowledge check; the sandbox exercises are assessed by observation against the pass criteria above. Results are recorded against the user in the Learning Portal and feed the readiness dashboards reviewed at PMO Sync every Monday.
