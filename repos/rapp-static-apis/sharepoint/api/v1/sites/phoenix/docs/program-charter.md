# Project Phoenix — S/4HANA Transformation Program Charter

**Company:** Meridian Manufacturing Group (fictional demo company)
**Program:** Project Phoenix — ECC 6.0 → SAP S/4HANA (greenfield core, selective data transition)
**Sponsor:** Henrik Larsen, CFO (Steering Committee Chair)
**Program Director:** Katrin Vogel (katrin.vogel@meridian-mfg.example)
**PMO Lead:** Oliver Brandt (oliver.brandt@meridian-mfg.example)

## Objectives

1. Replace the aging ECC 6.0 core with SAP S/4HANA across all 8 company codes and 12 plants.
2. Standardize the global template: one chart of accounts (MERI), harmonized master data, common P2P / O2C / R2R processes.
3. Reduce period-end close from 9 days to 4 days.
4. Retire 41 legacy bolt-on systems by end of Wave 2.

## Waves

| Wave | Scope | Go-Live |
|------|-------|---------|
| Wave 1 | Germany (company code 1000: plants M001, M002, M003) and North America (company code 2000: plants U001, U002) | **December 2026** |
| Wave 2 | France (1100), Mexico (2100), China (3000), India (3100), Brazil (4000), Japan (5000) | June 2027 |

## Workstreams

Eight delivery workstreams: Finance (FI/CO), Procurement (MM/Ariba), Sales & Logistics (SD/LE),
Manufacturing (PP/QM), Data Migration, Technical Architecture & Basis, Change Management & Training,
Testing & Quality. Ownership and contacts: see the **Workstream Directory**.

## Guiding principles

- Fit-to-standard first; custom code requires a Design Authority exception.
- One global template, localized only where legally required.
- Every workstream decision >€50k impact goes to the Design Authority board.
