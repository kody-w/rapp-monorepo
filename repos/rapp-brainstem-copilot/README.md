# RAPP Brainstem for Copilot CLI

Paste into GitHub Copilot CLI: `Set up the RAPP Brainstem from kody-w.github.io/rapp-brainstem-copilot`

The page walks Copilot through the Brainstem installer and registers the shared MCP bridge ([rapp-brainstem-claude/brainstem_mcp.py](https://github.com/kody-w/rapp-brainstem-claude/blob/main/brainstem_mcp.py)) with `copilot mcp add`.

Live: https://kody-w.github.io/rapp-brainstem-copilot/
