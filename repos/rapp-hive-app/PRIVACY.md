# Rapp Hive Privacy Policy

_Last updated October 17, 2026_

Rapp Hive’s developer operates no AI server and receives no AI conversations. Its brainstem runs on your device, with Apple’s on-device model or, only after explicit AI-sharing permission and GitHub sign-in, GitHub Copilot. GitHub processes personal data you choose to send. Its developer never receives your conversations, voice, memories, agents, or settings.

## Permission before sharing with AI

Selecting GitHub Copilot in Settings first shows an AI data-sharing disclosure naming GitHub (a Microsoft company), the data sent, and its purpose. Allow AI data sharing is a separate choice from GitHub sign-in. Not now makes no GitHub request and leaves Apple’s on-device model or the labelled local demo available. Saved GitHub credentials alone never grant permission.

Permission is stored on this device for this disclosure version. A changed disclosure requires a new approval. Revoke AI data sharing in Settings stops further GitHub requests, cancels active requests and signs you out. Erase all data also clears permission. Neither action can recall data already received by GitHub.

## What the app stores on your device

Who answers on this iPhone (Apple’s model or GitHub Copilot, and which Copilot model) and whether replies are spoken aloud, in the app’s private on-device storage.

What you ask the brainstem on this iPhone to remember. Its memory agents save those notes in the app’s private storage, protected by your iPhone’s passcode, and read them back to answer you. With Apple’s on-device model answering, they never leave the device; with GitHub Copilot answering, recent memories go to GitHub Copilot with each question, as described below. Erase all data deletes them.

Your GitHub sign-in, only if you sign in for GitHub Copilot: the tokens GitHub issues are kept in the device keychain, limited to this device. Signing out, or erasing all data, deletes them.

Conversations and agent cards are kept in memory while the app is open. They are cleared when you start a new conversation, erase data, or close the app. Export transcript saves the conversation as a file that goes only where you send it, and Import transcript reads only the file you pick.

## What leaves your device, and where it goes

When Apple’s on-device model answers on this iPhone, what you say or type is not sent anywhere.

Only after you allow AI data sharing, GitHub Copilot receives typed questions or transcribed speech, recent conversation messages, recalled saved memories, agent instructions and tool results included in answers, to authenticate your account and generate AI replies. GitHub also receives sign-in requests and tokens, your IP address and service request metadata. No audio is sent to Copilot. Sign-in uses a one-time code on GitHub’s website; HIVE never sees your GitHub password.

GitHub, Inc. or GitHub B.V. operates GitHub Copilot as a Microsoft company. Its privacy statement is https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement and the terms that cover Copilot are https://docs.github.com/en/site-policy/github-terms/github-terms-for-additional-products-and-features. These policies describe safeguards, purposes, retention, subprocessors and privacy rights. GitHub Copilot is the only third-party AI service that receives your conversation content from Rapp Hive. Before offering it, we reviewed GitHub's privacy statement and confirm that GitHub provides the same or equal protection for that data as this policy: GitHub states that it does not sell personal data, protects data with security safeguards such as encryption and access controls, and offers access and deletion rights, subject to applicable law and its retention exceptions. When GitHub Copilot is used, GitHub also receives product-interaction and request metadata and may use it for service analytics and improvement under its privacy statement and your account settings. Retention and model-improvement use depend on your plan and account or organization settings; HIVE does not promise that GitHub immediately deletes prompts or never uses them for model improvement. Manage those settings and deletion requests with GitHub.

When you ask about Hacker News, the brainstem’s Hacker News agent fetches public stories from Hacker News’s API. Like any website, Hacker News receives your IP address and standard request details; nothing you said or saved is sent.

A card’s sharing code carries only an agent’s recipe — its name, description, steps, and parameters — never code, and only when you show it to someone.

## Voice

On iOS, the microphone is used only while you talk to the orb, after permission. Speech recognition is required to run on the device: if unavailable, HIVE asks you to type instead and does not fall back to a cloud speech service. Only the resulting text reaches the selected AI, and GitHub receives it only after AI-sharing permission. Spoken replies use the device’s built-in voice.

## Sharing a card, and contacting us

Share card opens your device’s share sheet with a picture of the card, its name, verdict, and summary, a link to Rapp Hive on the App Store, and, for a recipe card, its rapp://agent link. They go only to the apps and people you choose, and Save Image adds the picture to your photos. The picture is made on this device and saved only as a temporary file for the share sheet; the app never reads your photo library.

Become a founder opens your own mail app with a message addressed to us; nothing is sent unless you send it. When you email us, we receive your email address and what you write, and use them to reply, to keep track of founders and their perks, and to send the weekly founders email you asked for. Every weekly email has an unsubscribe link, you can ask us to delete your address at any time, and we never sell or share it. If you join the Founders Club on Discord, Discord’s own terms and privacy policy apply there.

## What the app does not do

There are no Rapp Hive accounts, and Rapp Hive’s developer runs no analytics, advertising, or tracking. GitHub Copilot receives what you say only after explicit AI-sharing permission and sign-in. Nothing you open or scan runs until you approve it (see Cards).

## Cards

A card is a small program (a “Zap”) that Rapp Hive can run on your device for your brainstem, such as a weather lookup. Cards come from you: the Day One cards shipped inside the app, a card you scan or receive from someone, or a card your brainstem writes when you ask it to. A card is text you can read in full on its back; the app reads it without running it and shows what it asks for, which is at most reading named public websites over https and keeping a small memory of its own on your device. Nothing runs until you tap Approve on that card, and you can revoke or remove it at any time; revoking stops it at once. A card never receives your conversation, your memories from other agents, your account details, or anything outside what it asked for, and approvals stay on your device: when you pass a card to someone, your approval does not go with it. Cards run inside the app, in a sandbox provided by Apple's JavaScriptCore, with limits on time and memory. Erase all data removes every card and every approval.


### Cards that run on their own, notifications, the widget, Siri

A card you set to run every day runs on this iPhone at about the time you chose, in the background when iOS allows it or when you next open the app. What it answered is kept on this device as its last run. If you turn on "Tell me when it has run", iOS shows a notification made on this iPhone with the card's name and one line of its answer; nothing is sent to a notification service. The HIVE widget shows the name, time and one line of your cards' last runs on your lock screen or home screen, where anyone who can see your screen can read them; remove the widget or the card to stop that. Siri and the Shortcuts app can run only cards you approved, through Apple's App Intents on this iPhone; a card run that way is kept as its last run the same way.

### Hive Pro

Hive Pro is a subscription sold by Apple through the App Store. Apple handles payment; Rapp Hive sees only whether the subscription is active, never your payment details. Erase all data does not cancel a subscription: manage it in Settings › Apple Account › Subscriptions.

## Your control

Revoke AI data sharing, sign out of GitHub, turn spoken replies off, or erase all app data in Settings at any time. Erase all data deletes local memories, clears AI-sharing permission and signs you out of GitHub. Data already sent to GitHub is governed by GitHub’s retention and deletion policies. Deleting the app removes its app-container data; use Erase all data before deletion to remove device-keychain credentials as well.

Your device may include the app’s settings and saved memories in iCloud or computer backups, according to your device settings. The GitHub sign-in is saved with this-device-only protection, so it does not sync through iCloud Keychain or move to a new device.

## Children

HIVE is not directed at children under 13. The developer does not knowingly collect children’s personal data. Optional GitHub use is subject to GitHub’s age requirements and privacy protections.
