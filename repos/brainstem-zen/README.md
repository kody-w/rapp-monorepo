# Brainstem Zen Benchmark: the public looking glass

**Stronger models. Same wood. Same water.**

Public scorecard: <https://kody-w.github.io/brainstem-zen/>.
This static repository is the public half of the **Looking Glass pattern**:
frontier investigation stays in a private tent; approved, sanitized data exhaust
is visible here. It never operates a visitor's Brainstem or calls an AI provider.

The first participant is **GPT-6.1 Sol**, in a history-informed calibration on
Grail `0e43ee580e78c150b1c59002456822d2e779388e`.
The existing suite passed 223 tests, with one POSIX-only Windows skip. Three
correctness findings earned trials, including a real-browser reproduction of
one instruction causing two synthetic marker actions.

Two prior Luna discovery lanes then explored conservative and creative biases.
Fresh **Sol 6.1** and retrospective **Luna 6** judged all five anonymous proposals
against the same frozen evidence and taste rubric. Both put the once-only chat
promise first: **100 versus 87**. Those are provisional AI taste scores, not IQ
scores or release approval. One ambiguous repeat was rejected, not averaged.
The ledger is ready for future retrospective and same-alias observations;
temporal drift has not yet been measured.

**No fixes have been admitted or shipped.** No VM or live-provider acceptance
is claimed, and no prior model was given a matched blind comparison.
`results.json` is the readable public record. The interactive counter replays
recorded fixture observations; it is not a live test.

Feedback concerns the open-source Brainstem engine, but public results do not
release private prompts, holdouts, probe implementation, or admission internals.
