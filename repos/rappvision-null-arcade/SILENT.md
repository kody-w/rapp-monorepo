# SILENT — Null Arcade

No narration is used. This is intentional: the speedrun grammar depends on
rapid, readable on-screen commands rather than a voice competing with the timer.
The original synthetic chipwave track supplies pace and punctuates the verified
finish, cheat rejection, replay handoff, and closing lockup.

The replay orientation is explicit on screen:

1. Follow `START → BOOST → JUMP → FINISH`.
2. `CHEAT` is rejected and cannot replace the verified score.
3. `RESET` starts a new run while preserving the verified record.
