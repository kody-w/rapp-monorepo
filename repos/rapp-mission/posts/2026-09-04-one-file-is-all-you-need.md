# One file is all you need

*2026-09-04*

Every few weeks there is a new video explaining the eight concepts you must learn before your AI
can help you. Templates, context, memory, routines, logging. It is well meant. It is also the
problem.

You should not have to learn how a thing is made to be good at using it. Nobody learns how a
phone is built before they call their mother.

So here is the whole idea. You own one file. It says who you are, how you like to be helped,
what you are working on, and what you have taught your AI along the way. Any AI that reads
skills reads that file. Move from one tool to another and it comes with you, unchanged. The new
AI just knows you.

A capability is one file too. Put it where your AI reads skills and ask for it in plain words. It
runs, because the code is inside the file. Want to share it? Send the file. Want it gone? Delete
the file. Your AI is exactly how it was before.

There is nothing to install and nothing to learn. That is not a feature we added. It is the
whole product. If we ever need a glossary to explain it, we got it wrong.
