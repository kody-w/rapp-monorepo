# Delete it and you are back

*2026-09-04*

Here is a promise most software will not make: if this ever gets in your way, delete one file
and you are back to exactly where you started.

No uninstaller. No settings to undo. No background process to hunt down. Nothing was changed
outside the file, so removing the file removes all of it. We tested this by running a skill inside
an empty home folder and counting what it wrote there. Zero files.

Why does that matter? Because being easy to leave is how you earn the right to stay. A thing that
is hard to remove has to be defended. A thing that costs nothing to remove only has to be
useful.

It also keeps us honest. We cannot lock anyone in, so the only way to keep people is to keep
being the thing that makes their AI better. That is a good constraint to build under.
