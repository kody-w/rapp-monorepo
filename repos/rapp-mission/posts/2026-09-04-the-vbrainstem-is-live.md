# The vbrainstem is live

*2026-09-04*

Today the first person's file went live. Its owner calls it his vbrainstem, a virtual brainstem:
one file that makes any AI his.

Here is what happened, in order, all on the same afternoon.

He put the file where Claude Code reads skills. A brand new session, told nothing else, was asked
what "done" means to him and which two parts of his life he keeps apart. It answered both,
correctly, on the first turn.

He put the same file where GitHub Copilot reads skills. A brand new session there answered the
same questions the same way.

Then a line was added to the file's memory. Seconds later another fresh session was asked what he
calls his personal file and one thing he remembers from today. It knew both. No code ran. The
file was simply read again, as it is at the start of every task, and the new line was in it.

Then the file was dropped into his own local runtime, the one that existed long before any of
this. It appeared as one of that runtime's own tools with no restart, and a real conversation
used it to answer the same "done" question. The runtime is now one more place the file works,
not a requirement for it.

That is the whole product in one afternoon: one file, three different AIs, the same person
recognized in each, memory that travels, and a way out that costs one delete.

Nothing in the file names the machinery. It has an identity of its own, minted once, tucked in a
header no person reads. What the person reads is a page about themselves, written in their own
words, that any AI can pick up and act on.

We think this is what "my AI" should mean. Not an account. Not a subscription. A file you own.
