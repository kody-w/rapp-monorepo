# The RAPP mission

**AI for everyone, wherever they are, on whatever they have, with whatever AI they already use,
without going to school for it.**

This repository is the canonical, dated statement of what we are doing and why. It holds no
code. The code that carries it out lives in [rapp-skills](https://github.com/kody-w/rapp-skills).

## The idea in one paragraph

A person owns one file. It is everything that makes their AI theirs: who they are, how they like
to be helped, what they are working on, what they have taught it. Any AI that reads skills reads
it, and the person's AI moves with them from one tool to the next, unchanged. Capabilities are
one file each too: put one where your AI reads skills, ask for it in plain words, and it runs,
because it carries its own code. Nothing to install, nothing to learn, and deleting the file
returns the AI to exactly how it was. Underneath, one medium carries every file the same way
across devices and AIs. It is invisible on purpose.

## The first one

The first such file exists as of 2026-09-04: its owner's own, loaded into Claude Code and GitHub
Copilot CLI. Told nothing else, a fresh session in each answered what "done" means to him and
which two worlds he keeps apart. It has its own identity, minted once. Nothing about how it is
made shows in what the AI reads.

## The key: the same experience everywhere

The whole point is consistency. The same file behaves the same way, feels the same way, and
knows the person the same way in Claude Code, in Copilot, on a laptop, on a phone, and on
whatever ships next year. A person should never have to relearn their own AI because they
changed tools. Everything we build is judged by whether it keeps that promise.

## The ark

Let every platform commoditize inside its own bubble. That is fine, and it is not our fight. The
person's file is the ark: it keeps them in control and in command of their own AI wherever they
go, whichever bubble they happen to be standing in today. That is the purpose of the medium
underneath: the person carries their AI with them and never loses command of it.

## The fallback ladder

1. **The native platform does the work.** Claude Code, Copilot, or whatever comes next. We never
   build what it already builds.
2. **The file makes the platform better.** The person's file and their skills ride on top of the
   native tool and make it know them and do more. This is where all of our effort goes.
3. **The Brainstem is the last-case scenario.** Our own local runtime still exists and runs the
   very same file. It is there only if everything native has failed: no platform, no network, no
   account. It is never required, never suggested first, and a person can go their whole life
   without knowing it exists.
