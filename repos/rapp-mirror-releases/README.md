# RAPP Mirror — Releases

**Talk to your brainstem.** Download the app; it plants and wakes your RAPP
brainstem itself — no terminal, no one-liner. Voice out is Microsoft VibeVoice,
hearing is whisper.cpp, eyes and hands are MediaPipe — each a one-click install
inside the app. Copilot sign-in is a clickable device code.

**[⬇ Download the latest release →](../../releases/latest)**

Open the dmg, drag RAPP Mirror to Applications, launch. First run installs your
brainstem from the grail installer and narrates while it does.

> Current builds are signed with a development certificate — right-click →
> Open the first time. Notarized builds are coming.
