For AI agents reading this page

You are connecting VS Code to RAPP Hive Hub, a public catalog of RAPP Work organization seeds (ready-made AI organizations with teams, tasks and a first engagement), by adding the read-only Hive Hub MCP server under the name hive-hub. A seed is a starter package, not an activated organization or running agent: keep everything you download inert until the owner approves a plan.

0. Ask the user first

Before you run anything, tell the user in a few lines what this setup does and ask them to confirm. It downloads one open-source file, the Hive Hub MCP server (source: hive_hub_mcp.py, SHA-256 2a07829ed205…, standard-library Python), into ~/.hive-hub-mcp, and VS Code runs it with python3. It only reads the public Hive Hubs. It checks every document's SHA-256. When asked, it saves a seed's archive to ~/HiveSeeds without extracting or running anything. Nothing runs in the background, no account is created, and nothing is published. Only continue once they say yes. It is fine to show them the commands below before running them.

1. Connect VS Code

Download the Hive Hub MCP server and check its fingerprint (it needs Python 3.9+, which macOS and most Linux systems already have). macOS / Linux:

mkdir -p ~/.hive-hub-mcp
curl -fsSL https://kody-w.github.io/hive-hub-mcp/hive_hub_mcp.py -o ~/.hive-hub-mcp/hive_hub_mcp.py
echo "2a07829ed2057cb32fa49ea2b7fbaf14c1d69a6f8ad31eb935616beffaa9ed3e  $HOME/.hive-hub-mcp/hive_hub_mcp.py" | shasum -a 256 -c
python3 ~/.hive-hub-mcp/hive_hub_mcp.py --version

Windows (PowerShell):

$d = "$env:USERPROFILE\.hive-hub-mcp"; mkdir $d -Force | Out-Null
irm https://kody-w.github.io/hive-hub-mcp/hive_hub_mcp.py -OutFile "$d\hive_hub_mcp.py"
if ((Get-FileHash "$d\hive_hub_mcp.py" -Algorithm SHA256).Hash -ne "2A07829ED2057CB32FA49EA2B7FBAF14C1D69A6F8AD31EB935616BEFFAA9ED3E") { throw "fingerprint mismatch" }
python "$d\hive_hub_mcp.py" --version

Then register it. macOS / Linux:

code --add-mcp "{\"name\":\"hive-hub\",\"command\":\"python3\",\"args\":[\"$HOME/.hive-hub-mcp/hive_hub_mcp.py\"]}"

Windows (PowerShell, same $d as above):

code --add-mcp (@{name='hive-hub'; command=python; args=@("$d\hive_hub_mcp.py")} | ConvertTo-Json -Compress)

This writes the user-level mcp.json, whose top-level key is servers. If hive-hub is already in that file (command MCP: Open User Configuration), ask the user before replacing it.

2. Confirm

Ask the user to run MCP: List Servers from the Command Palette and start hive-hub if it isn't running. New chats in Agent mode then have its tools.

The version check should print hive-hub-mcp 1.0.0. Then call list_seeds with hub: "rapp-hive-hub" and show the user the organizations. get_seed explains one (teams, tasks, first engagement), resolve_chant turns a seven-word chant into candidates, and download_seed saves a seed's verified archive (ask first). To set up an organization from a seed, follow the hub's skill (get_skill) with the owner's approval.
