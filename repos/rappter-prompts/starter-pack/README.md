# Starter pack
The ten prompts in this library are the ten routines a RappterBox runs on day one. `routines.json` says, for each
one: when it runs, what it reads, what it writes (a rapp/1 receipt frame per run), what it will never do, and when
it stops and asks the owner.

`synthetic/` holds made-up businesses (clearly labelled SYNTHETIC) so a routine can be shown running on a real box
before a single real record is shared. Tell us how you do one job today, in your own words, on the waitlist form —
we run it through a real box on synthetic data before we ever talk, and show you the receipt.
